# 云程研 App MVP 范围

## 文档目的

本文定义云程研 App 首个可用版本的产品边界。产品仅供三人私用，不提供公开注册，APK 仅私下分发。

本文只确认产品能力与约束，不替代后续的数据模型、同步策略或工程实现设计。

## 使用者与访问方式

- 负责人在线下预置三枚一次性邀请码，并在线下交给三名使用者。
- 首次使用者可兑换邀请码，随后设置昵称、账号和密码。
- 邀请码成功兑换后不可再次使用。
- 已完成首次设置的使用者保持登录；换机后可使用账号和密码登录。
- 客户端不提供邀请码创建、查看、分发、撤销或补发等管理页面。

## MVP 主入口

完成身份验证后，产品提供四个主入口：

| 主入口 | MVP 能力 |
| --- | --- |
| 今日 | 展示今日概览；提供“快速开始”入口进入正计时专注。今日概览的具体指标与排版待决。 |
| 专注 | 从零开始正计时；由使用者主动结束；不提供预设时长或番茄钟。 |
| 小队 | 每人每天手动打卡一次；打卡由状态和可选的 0–140 字内容组成；不提供回复或独立留言。 |
| 我的 | 查看历史专注记录；查看日、周、月统计；查看同步状态；进入设置。统计指标、图表和具体设置项待决。 |

## MVP 业务规则

### 专注记录

- 专注使用正计时，不使用番茄钟或预设时长。
- 会话以完成时刻作为归属日期，日期按设备本地时间计算。
- 时长少于 1 分钟的会话不保存，也不计入统计；结束时必须明确提示使用者该会话将被放弃。
- 时长达到或超过 1 分钟的已完成会话可保存并进入统计。
- 已完成专注记录的时长不可编辑。
- 仅记录创建者可删除该记录，且删除前必须再次确认。

### 打卡

- 打卡每天由使用者手动提交一次。
- 完成专注不会自动生成打卡。
- 打卡包含一个状态和一段可选内容；可选内容允许为空，最多 140 字。
- MVP 不提供对打卡的回复，也不提供脱离打卡的独立留言。

### 统计

- 提供日、周、月三个统计粒度。
- 周范围为周一至周日。
- 专注会话按设备本地完成时刻归入对应日期；跨越午夜的会话归入完成日。
- 展示哪些指标、采用何种图表及历史统计受删除影响的规则仍待决定。

## 产品与技术约束

- 技术基线：经典 uni-app（不是 uni-app x）、Vue 3、TypeScript、Pinia、LeanCloud、本地优先。
- 固定边界：`Page -> Feature / Use Case -> Repository -> Mapper -> Platform Adapter`。
- Page 不得直接调用 LeanCloud；LeanCloud SDK 类型不得越过 Repository/Mapper。
- `uni.*`、设备、文件和网络等平台能力必须通过 Platform Adapter。
- 本地数据是首要可用来源；同步由基础设施负责，不由页面编排。

## v0.2 或以后

以下能力不属于 MVP，不得在 MVP 页面或验收中表现为可用：

- 独立留言；
- 笔记；
- 错题；
- 附件；
- 排行榜；
- 公开注册；
- 番茄钟。

## 待决项

下列事项没有在本任务中确定，后续必须单独决策：

- 今日概览的具体内容、指标和排版；
- 首次进入页的具体视觉结构，以及登录与邀请码兑换是否合并为一页；
- 昵称、账号和密码的格式、唯一性、校验规则，以及账号找回或密码重置方式；
- 邀请码的格式、有效期和兑换失败提示；
- 专注计时的暂停、后台运行、异常退出和设备重启处理；
- 短会话放弃提示是否需要二次确认、能否取消，以及取消后是否恢复当前计时；
- 打卡状态的可选值，以及打卡的编辑、删除与跨日边界规则；
- 历史列表的范围、排序、筛选，以及删除记录后统计如何变化；
- 日、周、月统计的具体指标、图表、时间选择器和空状态；
- 同步触发时机、状态枚举、失败重试、冲突策略，以及离线状态下各动作的产品反馈；
- 设置页的具体项目；
- LeanCloud 类、字段、ACL 与身份授权方案。
