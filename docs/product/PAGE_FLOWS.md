# 云程研 App MVP 页面流程

## 流程约定

- 完成身份验证后，四个主入口为“今日”“专注”“小队”“我的”。
- 文中“本地日期”仅用于已确认的专注统计规则，取设备本地时间。
- 未在流程中定义的文案、视觉形式、异常恢复和同步策略均不视为已确定。

## PF-01：首次进入与邀请码注册

**前置条件**：设备上没有有效登录会话，使用者持有负责人线下提供的一次性邀请码。

1. 使用者首次打开 App，进入身份入口。
2. 使用者选择邀请码注册并输入邀请码。
3. 系统校验并兑换邀请码。
4. 兑换成功后，系统要求使用者设置昵称、账号和密码。
5. 设置成功后，系统建立登录会话并进入“今日”。

**成功结果**：该使用者可使用四个主入口，且该邀请码不能再次兑换。

**失败结果**：无效或已兑换的邀请码不得创建账号；页面保留在身份流程并给出失败反馈。具体邀请码校验规则和反馈文案待决。

**边界**：客户端不提供任何邀请码管理入口。

## PF-02：账号密码登录与保持登录

**前置条件**：使用者已通过邀请码完成首次设置；当前设备没有有效登录会话。

1. 使用者在身份入口选择账号密码登录。
2. 使用者输入账号和密码并提交。
3. 验证成功后，系统建立登录会话并进入“今日”。
4. 在登录会话仍有效时再次打开 App，系统直接进入已登录状态，不要求重复输入邀请码。

**失败结果**：账号或密码验证失败时不得进入四个主入口，页面给出失败反馈。账号找回、密码重置和会话失效策略待决。

## PF-03：从今日快速开始专注

**前置条件**：使用者已登录。

1. 使用者进入“今日”，可看到今日概览和“快速开始”。
2. 使用者点击“快速开始”。
3. 系统进入“专注”并从零开始正计时。

**结果**：页面显示持续增加的已用时；流程不要求使用者选择目标时长，也不出现番茄钟入口。

## PF-04：结束达到 1 分钟的专注

**前置条件**：专注正在正计时，显示的会话时长达到或超过 1 分钟。

1. 使用者主动结束专注。
2. 系统停止计时并保存完成记录。
3. 记录保存完成时刻、最终时长和创建者归属；时长随后只读。
4. 该记录可在历史中查看，并按设备本地完成时刻计入日、周、月统计。

**结果**：会话被保存且进入统计。结束后的具体落地页面待决。

## PF-05：结束少于 1 分钟的专注

**前置条件**：专注正在正计时，显示的会话时长少于 1 分钟。

1. 使用者主动结束专注。
2. 页面明确提示：该会话过短，将被放弃、不保存且不计入统计。
3. 放弃提示是否需要二次确认、使用者能否取消，以及取消后是否恢复当前计时均待决；本流程不将其作为 MVP 已确认行为。

**已确认结果**：少于 1 分钟的已结束会话不创建专注记录，历史与统计中均不计入该会话。

## PF-06：每日手动打卡

**前置条件**：使用者已登录，并进入“小队”。

1. 使用者选择一个打卡状态。
2. 使用者可不填写文字，也可填写不超过 140 字的内容。
3. 使用者主动提交打卡。
4. 当日首次提交成功后，系统显示已打卡状态。
5. 同一使用者在同一天再次尝试提交时，系统不得创建第二条打卡。

**校验结果**：未选择状态或文字超过 140 字时不得提交成功。状态选项、一天的跨日边界、提交后的编辑或删除规则待决。

**独立性**：完成专注不会触发本流程，也不会自动改变当日打卡状态。

## PF-07：查看日、周、月统计

**前置条件**：使用者已登录，并从“我的”进入统计。

1. 使用者在日、周、月三个粒度之间选择。
2. 日统计按设备本地完成日期归集已保存的专注会话。
3. 周统计使用周一至周日的范围。
4. 月统计按设备本地完成日期归入对应月份。

**边界示例**：一段会话在本地时间周一 23:58 开始、周二 00:02 完成，应归入周二所在的日、周和月统计。

**待决**：统计指标、图表、空状态、日期切换方式及删除记录后的重算规则。

## PF-08：删除历史专注记录

**前置条件**：使用者从“我的”进入历史，并打开一条已完成专注记录。

1. 页面以只读方式展示该记录的已完成时长，不提供时长编辑入口。
2. 如果当前使用者不是记录创建者，页面不得提供可成功执行的删除动作。
3. 如果当前使用者是记录创建者并发起删除，页面先显示确认提示。
4. 使用者取消确认时，记录保持不变。
5. 使用者确认删除时，系统删除该记录。

**结果**：只有创建者在二次确认后才能删除记录。删除后的统计重算与同步行为待决。

## PF-09：同步状态与设置入口

**前置条件**：使用者已登录并进入“我的”。

1. 页面提供同步状态的可见入口或区域。
2. 页面提供设置入口。

**待决**：同步状态的枚举、刷新与重试动作、冲突反馈、离线反馈，以及设置页的具体项目。

## 不存在于 MVP 的页面流程

MVP 不提供独立留言、笔记、错题、附件、排行榜、公开注册、番茄钟或客户端邀请码管理流程。
