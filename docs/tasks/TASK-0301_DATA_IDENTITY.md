# TASK-0301：数据、身份、ACL 与同步设计

## 目标

生成一份可审阅的数据与身份设计基线，明确已确认约束、候选建议和实施前待决事项，为后续数据模型、ACL、受控邀请码兑换与本地优先同步决策提供批准入口。

## 范围

- 记录三人私用、无公开注册、三枚线下预置一次性邀请码与注册后保持登录的身份生命周期。
- 固定客户端、Repository/Mapper、Platform Adapter 与受控基础设施之间的信任边界。
- 描述本地优先读取、写入与同步职责、离线语义和最小权限目标。
- 收录已确认的打卡、专注记录、统计与删除业务约束。
- 将尚未批准的数据模型、ACL、可见性、冲突、身份运维和同步细节明确保留为待决。

## 明确不做

- 不创建业务代码、LeanCloud 类或字段，不配置 ACL、云函数、appId、appKey、MasterKey 或用户数据。
- 不选择或部署邀请码兑换的具体服务端/受控基础设施。
- 不安装 Node、HBuilderX、Android SDK 或其他软件。
- 不修改 `docs/PROJECT_STATUS.md`、`docs/ROADMAP.md`、`docs/DECISIONS.md` 或 `CHANGELOG.md`。
- 不暂存、提交、推送、创建 PR、修改 Git/GitHub 设置或触碰 `main`。

## 产出文件

- `docs/data/IDENTITY_ACL_SYNC.md`：身份生命周期、邀请码信任边界、本地优先同步职责、离线行为、最小权限目标，以及已确认/推荐但待批准/待决的分类。
- `docs/tasks/TASK-0301_DATA_IDENTITY.md`：本任务的范围、产出、验证、风险与后续决策清单。

## 已确认与待决的边界

### 已确认

- 三人私用且无公开注册；负责人线下预置三枚一次性邀请码，客户端无邀请码管理页。
- 邀请码只在首次注册兑换；成功后设置昵称和账号密码，之后保持登录。
- 邀请码兑换由服务端或受控基础设施原子执行，客户端不是权限信任边界。
- 经典 uni-app Vue 3、TypeScript、Pinia、LeanCloud、本地优先及固定分层边界。
- Page 不直连 LeanCloud 或 `uni.*`，SDK 类型不越过 Repository/Mapper，同步由基础设施负责。
- 每日手动一次打卡；少于 1 分钟的正计时专注不保存；统计按本地完成时刻和周一至周日计算；记录时长不可编辑且创建者可确认删除。
- 当前没有 LeanCloud 配置、客户端标识、凭证或用户数据。

### 推荐但待批准

- 有效本地会话下的离线进入、会话材料最小化保存，以及联网后的会话校验/刷新。
- 可恢复的持久化同步状态、幂等重试、基础设施事件触发、有限并发与退避。
- 删除意图在远端确认前可恢复，以及向 UI 暴露领域化同步状态。
- 邀请码不可逆验证材料、兑换限流与不含秘密/正文的最小审计事件。

### 待决

- LeanCloud 类、字段、关系、约束、索引、标识映射、迁移与保留策略。
- 三名用户之间的数据可见范围和逐资源 ACL 权限矩阵。
- 邀请码受控执行设施、权限隔离、预置/撤销/丢失处理。
- 逐实体同步冲突、重复提交、删除传播、时钟偏差、版本与重试策略。
- 账号标识、密码与昵称规则、会话期限/撤销、换机、密码恢复和账号恢复。

## 风险

- “三人私用”不能自动推导三人互相可见；可见性未决定前若提前实现 ACL，可能造成越权读取或误阻断。
- 客户端若承担邀请码校验或消费，会受到篡改、重放和并发兑换攻击；必须保留受控原子执行边界。
- 未先逐实体批准冲突规则就实现同步，可能静默覆盖打卡、重复专注记录或复活已删除数据。
- 本地完成时刻用于统计，但设备改时钟、时区变化和跨设备并发尚未定义，可能造成日期归属不一致。
- “保持登录”的生命周期细节尚未定义；会话撤销、换机和密码恢复处理不当会造成可用性或数据残留风险。
- 当前没有 LeanCloud 配置和真实环境验证；本文不能证明具体 ACL 或同步实现安全有效。
